# Experiment results

Results are split by **how the drone was flown**:

```text
runs/
├── sim/       ← offline Python simulator  (--backend sim)
└── gazebo/    ← real PX4 + Gazebo flight  (--backend px4)
```

Open **`sim/`** or **`gazebo/`**, pick a run folder, start with **`00_run_report.md`**.

Full guide: [`../RUNS_GUIDE.md`](../RUNS_GUIDE.md)
